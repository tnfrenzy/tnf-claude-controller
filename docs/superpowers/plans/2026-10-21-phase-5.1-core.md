# Phase 5.1 — Lõi controller lập trình — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Controller tạo worktree + nhánh cho mỗi run `kind=coding`, cấp quyền theo SPEC §4.2–4.3, thu diff/test/verdict sau run, parser hiểu các sự kiện mới; tất cả kiểm bằng CLI giả (không gọi Claude thật).

**Architecture:** Thêm hai module thuần (`src/core/git.ts` spawn git không shell; `src/core/permissions.ts` dựng allowlist) và mở rộng `RunStore` (bảng `projects`, cột mới của `runs`), `StreamParser` (vcs.commit, agent.verdict, quy permission.denied, theo dõi output test), `RunManager` (nhánh coding/research, post-run), CLI/API `projects`. Cấu hình tách `defaults.coding` / `defaults.research`. CLI giả học cách tạo commit để nghiệm thu offline.

**Tech Stack:** Node 24 (`node:sqlite`, `child_process.spawnSync`), TypeScript, vitest, git CLI.

**Spec:** `docs/CONTEXT-SPEC-v1.md` §3, §4.2–4.3, §5.4, §7, §8, §10 (bước 5.1). Bằng chứng spike: `docs/SPIKE-RESULTS.md` S1–S7.

## Global Constraints

- Không `--bare`, không `bypassPermissions`; `--permission-mode dontAsk` + `--allowedTools` tường minh (CLAUDE.md quy tắc 1–2).
- Billing guard trước mỗi spawn; spawn không shell; file cho `--agents`, `--settings`, `--append-system-prompt-file` (quy tắc 3–4).
- Git của controller: `spawnSync("git", [...])` không shell, cwd tường minh, env agent `GIT_AUTHOR_NAME=TNF Agent`, `GIT_AUTHOR_EMAIL=agent@example.com`, `GIT_COMMITTER_*` giống, `GIT_TERMINAL_PROMPT=0` (SPEC D13, §4.3, §9).
- Worktree: `D:\tnf-claude-workspace\worktrees\<run-id>` (cấu hình `worktreesDir`), nhánh `tnf/<run-id>` tách từ `project.base_branch`; **không xóa** worktree tự động (D12).
- Allowlist coding = hợp vai (§4.2) + `project.allowed_commands` (mỗi mục `Bash(...)`, phần cố định không chứa `;`, `&&`, `|`), `Edit(<wt>/**)`, `Write(<wt>/**)`, `Write(<run-dir>/notes/**)` dùng dấu `/`. Deny qua `config/deny-settings.json` + `--disallowedTools` 3 mục. `extraArgs` coding mặc định `["--setting-sources","project"]`.
- Run `kind=research` giữ nguyên hành vi hiện tại (cwd `runs/<id>`, bộ vai cũ).
- Không chạy claude thật trong phiên này; mọi test dùng `fixtures/fake-claude.mjs`.
- Mã, commit tiếng Anh; thông báo hiển thị tiếng Việt. Commit nhỏ theo từng task với `git -c user.name=dev -c user.email=agent@example.com`.
- Mọi bước xong ghi bằng chứng vào `docs/PROGRESS.md`.
